# Icon source

`icon.png` is the unmodified 256 px PNG image embedded in the official
[Steam website](https://store.steampowered.com/) favicon.

Source: https://store.steampowered.com/favicon.ico

Retrieved 2026-09-25. The PNG payload was extracted from the ICO container
without resizing or recoloring. Used to identify the source application.

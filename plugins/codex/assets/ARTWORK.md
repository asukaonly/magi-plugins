# Magi plugin artwork

Original vector artwork for Magi. Distributed under this repository's license.

- `group-icon.svg`: agent history identity.

Designed on a 64-unit grid for 24–32 px display on light and dark surfaces.
Group artwork is intentionally identical in each member package; entry icons
retain their own product identities. Assets are self-contained SVGs with flat
fills and contain no fonts, remote content, or runtime styling.
